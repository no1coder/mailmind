# MailMind

**开源的 macOS 原生 AI 邮件管家** —— 统一管理多个邮箱，让 AI 自动分类、摘要、翻译，重要邮件即时通知，其余邮件定期汇总。

> 当前版本 0.1.0，处于早期开发阶段，同步为**只读**模式（不会修改、删除或标记服务器上的邮件）。

## 功能

- 📮 **多邮箱统一管理**：只输入邮箱和授权码即可，服务器自动识别（内置预设 → Thunderbird 配置库 → 常见主机名探测）；支持**批量导入**，一次粘贴多个账户并逐个测试；账户状态一目了然（绿 = 实时推送，蓝 = 轮询，红 = 出错）
- ⚡ **实时推送**：支持 IMAP IDLE 的邮箱新邮件秒级到达，不支持的每 5 分钟轮询，Mac 唤醒后立即补拉
- 🤖 **AI 理解每封邮件**：8 种分类、重要程度、**一句话总结**（「王经理：周五前确认 Q4 预算」）、待办、截止日期、验证码提取、外语全文翻译
- 🔔 **克制的通知**：只有真正需要马上知道的才响铃，其他重要邮件静默进入通知中心，营销资讯只进汇总；勿扰时段、VIP、静音发件人、多封合并，通知上可直接「复制验证码」「标为已读」
- 💬 **问 AI（⌘K）**：「这周有哪些账单要付？」，回答附带可点击的原邮件
- ✍️ **AI 起草回复**：一句话说明意图，生成同语言的回复，一键在邮件 App 中打开
- 🧠 **越用越懂你**：「以后该发件人都归为营销」等发件人规则，命中低价值分类时不再调用 AI，省钱又更准
- 📰 **定期汇总**：每天 / 每周把非重点邮件整理成摘要，并给出退订建议
- ⌨️ **键盘优先**：⌘1-4 切换视图，⇧⌘U 已读 / 未读，⌘R 同步，⌘K 问 AI，多选批量操作，按今天 / 昨天 / 本周分组
- 🛡️ **隐私与安全**：只读同步；密码和 API Key 存在钥匙串；HTML 邮件禁用脚本、默认拦截追踪像素；可用 Ollama 完全本地运行
- 🧩 **AI 服务可插拔**：任何 OpenAI 兼容接口 —— DeepSeek、通义千问、Kimi、硅基流动、OpenAI、OpenRouter、Ollama、LM Studio

## 安装与运行

需要 macOS 14+ 与 Xcode 15+（Swift 5.10+）。

```bash
git clone <repo-url> mailmind && cd mailmind
make run        # 编译、打包为 build/MailMind.app 并启动
make install    # 安装到 /Applications
make test       # 运行单元测试
```

开发调试也可以直接 `swift run`，但此时没有 bundle identifier，系统通知不可用。

## 快速上手

1. 打开 **设置 → 账户**，点 `+` 添加邮箱。输入邮箱地址后会自动识别服务商。
   - QQ / 163 / 126 等国内邮箱需先在网页版开启 IMAP，并使用**授权码**代替密码
   - Gmail / iCloud / Yahoo 需要**应用专用密码**
2. 打开 **设置 → AI 服务**，选择服务商、填写 API Key，点「测试连接」。
3. （可选）在 **分类规则** 中写下你自己的规则。
4. 在 **通知与汇总** 中设置同步频率、汇总时间，开启「登录时自动启动」。

首次启动会出现三步设置向导。首次同步只拉取最近 3 天（可配置）的邮件，之后增量同步新邮件。

## 架构

```
Sources/MailMind/
├── App/            应用入口、菜单栏
├── Mail/           IMAP 客户端（Network.framework）、MIME 解析器、服务商预设
├── AI/             OpenAI 兼容客户端、分类 / 翻译 / 汇总提示词
├── Storage/        SQLite 本地库、钥匙串、设置
├── Services/       同步引擎、通知、全局状态
└── Views/          SwiftUI 界面
```

数据流：`IMAP 同步 → MIME 解析 → SQLite → AI 分析 → 通知 / 汇总 → 界面`

本地数据位于 `~/Library/Application Support/MailMind/mailmind.sqlite`。

## 隐私说明

使用云端 AI 服务时，邮件的发件人、主题和正文（截断至 8000 字）会发送到你配置的 AI 接口。如介意，请使用 Ollama 等本地模型。MailMind 本身不收集任何数据。
